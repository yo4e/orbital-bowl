# ORBITAL BOWL

小惑星の重力を調律し、軌道に乗せたボールで惑星の裏側にあるピンを狙う、ブラウザ向け3Dボウリングゲームです。インストールやログインは不要で、PCブラウザを主対象に、横向きのモバイル画面にも対応します。

![ORBITAL BOWL コンセプトアート](./ChatGPT%20Image%202026%E5%B9%B48%E6%9C%884%E6%97%A5%2009_33_55.png)

## 初版の内容

| 領域 | 実装内容 |
|---|---|
| 3Dワールド | 低ポリ小惑星、抽象建築、10本のピン、軌道環、星空、柔らかな照明 |
| 物理・ゲーム性 | 小惑星中心へ向かうゲーム向け重力、発射、軌道の先読み、ピン転倒、最大3投のラウンド |
| 操作 | ドラッグまたはANGLE、ホイールまたはVELOCITY、GRAVITY、SPACE／LAUNCH、R、M、F |
| 記録 | スコア、ベストスコア、サウンド設定を `localStorage` に保存 |
| 表示 | 左下の観測機器風インストゥルメント、右上の投球・ピン・ベスト記録、縦画面での横向き案内 |

> 厳密な天体物理の再現ではなく、予測軌道を読み、少しずつ値を調整して成功へ近づくためのゲーム向け数値シミュレーションです。

## 操作

| 入力 | 操作 |
|---|---|
| ドラッグ | 投球角度を調整 |
| ホイール | 初速を調整 |
| ANGLE / VELOCITY / GRAVITY | 投球角度、初速、重力を調整 |
| `Space` または `LAUNCH` | ボールを発射 |
| `R` | ラウンドを最初からやり直す |
| `M` | サウンドを切り替える |
| `F` | 全画面表示を要求する |

## ローカルでの起動

```bash
pnpm install
pnpm dev
```

ブラウザで表示されたローカルURLを開きます。決定論的な自動投球を表示する確認用モードは、URL末尾に `?demo` を付けて起動できます。

```bash
pnpm check
pnpm build
```

## 技術構成

初版は、Reactを表示用フレーム、Babylon.jsを3Dキャンバスとして使う静的フロントエンドです。ゲームロジックは `client/src/game/` 以下のフレームワーク非依存のTypeScriptクラスに分離しています。バックエンド、外部API、データベース、認証、広告、課金機能は使用しません。

| 用途 | 技術 |
|---|---|
| 開発・ビルド | Vite、TypeScript、pnpm |
| 3D描画 | Babylon.js |
| UI | React、HTML、CSS |
| 保存 | `localStorage` |

詳細なゲームデザインは [DESIGN.md](./DESIGN.md)、実装構造は [STRUCTURE.md](./STRUCTURE.md)、制作計画とアセット方針は [PLAN.md](./PLAN.md) と [ASSETS.md](./ASSETS.md) を参照してください。
