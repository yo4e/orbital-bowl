# ORBITAL BOWL

小惑星の重力を利用してボールを軌道に乗せ、惑星の裏側にあるピンを倒すブラウザ向け3Dボウリングゲームです。

> 現在は構想・設計段階です。ゲーム本体の実装にはまだ着手していません。

## コンセプト

方向、初速、重力を調整し、ボールを小惑星の裏側まで回り込ませてストライクを狙います。

静かな宇宙、ローポリ建築、柔らかな光と音を組み合わせた、チルでアート寄りのインディーゲームを目指します。

## 想定ターゲット

インディーゲームが好きなZ世代女性を中心に、一目で世界観に惹かれ、短時間でも気持ちよく遊べる体験を想定しています。

表面的な「女性向け」装飾ではなく、次の要素を重視します。

- 静かで美しい世界観
- 直感的な操作
- スクリーンショットや短い動画で魅力が伝わる画面
- かわいさと知性が両立したデザイン
- 強い課金圧、広告、ログイン義務がないこと

## 想定環境

- PCブラウザを主対象
- スマートフォンは横画面対応を検討
- インストール・ログイン不要
- 外部API、データベース、SQL、有料サービスは使用しない
- セーブデータは端末の `localStorage` に保存

## 想定技術

- Vite
- TypeScript
- Three.js
- Rapier.js
- HTML / CSS
